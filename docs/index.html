BLA: Open-Source Shield That Poisons Binaries and JS Bundles Against AI Reverse-Engineering Agents

BLA (Blind LLM Agents) is a TypeScript/Python toolkit that injects adversarial noise into compiled binaries, Electron apps, JS bundles, Python, and WebAssembly to defeat AI-powered reverse-engineering tools like REA. Why it matters: If you ship compiled software or obfuscated JS, AI reverse-engineering agents are a real and emerging threat — this is the first credible open-source counter-toolkit worth evaluating.
